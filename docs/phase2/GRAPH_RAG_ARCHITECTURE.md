## 1. Architectural Philosophy: The Graph-RAG Duality

Standard RAG systems treat information purely as unstructured text passages embedded into vector spaces. While adequate for conversational search, this approach fails in financial blockchain forensics:
1. **Financial Heterophily**: Over 95% of Bitcoin transactions are licit. Pure text search cannot compute structural fund flows, counterparty risk, or topological neighborhood smearing.
2. **Deterministic Facts vs. Interpretive Explanations**: Transaction values, in-degrees, model probabilities, and edge lists are immutable mathematical facts that must never be generated by stochastic language models.
3. **Epistemic Modesty**: Model predictions must be framed with their known statistical boundaries and ablation characteristics.

To solve this, **ETGNN-Agent Graph-RAG** divides evidence into two complementary retrieval tracks:

## 2. Track A: Structured Graph & Deterministic Model Evidence

Track A operates via direct programmatic interfaces exposed by `InvestigationToolRegistry` (wrapping `ResearchDataLoader`):
1. **O(1) Node & Degree Lookup**: Uses precomputed NumPy in-degree and out-degree tensors derived from `elliptic_txs_edgelist.csv` (234,355 edges).
2. **Bounded BFS Neighborhood Extraction**: Extracts directed subgraphs up to 2 hops, capped at a maximum of 100 nodes to prevent unbounded memory growth on high-degree exchange hubs.
3. **Multi-Model Consensus Execution**: Executes inference across:
   - Canonical ETGNN (Dynamic GAT with sinusoidal time embeddings).
   - Random Forest (165 tabular features, max depth 12).
   - XGBoost (`scale_pos_weight=10.0`).
   - Residual ETGNN (Ego-skip GAT on 93 local features).
4. **Model Disagreement Quantification**: Automatically computes probability spread:
   $$\Delta P = |P_{\text{RF}} - P_{\text{ETGNN}}|$$
   If $\Delta P \ge 0.30$, flags structural divergence and surfaces the academic rationale (heterophilic neighborhood smearing in GNN convolutions vs. clean local tabular feature detection).

## 3. Track B: Research Knowledge Retrieval

Track B operates via `PersistentVectorStore` and `HybridRetriever`:
1. **Approved Document Ingestion**: Ingests exclusively from a cryptographically monitored allowlist:
   - `results/tables/final_test_results.csv` (Tier 1)
   - `docs/phase1_5/CHECKPOINT_REPRODUCIBILITY_REPORT.md` (Tier 1)
   - `docs/phase1_5/TEMPORAL_LEAKAGE_AUDIT.md` (Tier 2)
   - `docs/phase1_audit/ETGNN_MODEL_BASELINE_REPORT.md` (Tier 2)
   - `docs/phase1_5/SNAPSHOT43_CAUSALITY_REVIEW.md` (Tier 4)
2. **Section-Aware Chunking**: Markdown documents are parsed along structural heading hierarchies (`#`, `##`, `###`), ensuring numerical tables and qualifying disclosures are never split from their context.
3. **Reproducible Local Embeddings**: Uses scikit-learn's sublinear TF-IDF vectorizer ($5,000$ dimensions, n-grams $1..2$, L2 normalized) to provide fast, deterministic, zero-network-dependency semantic vectors.
4. **Hybrid Scoring Function**:
   $$S_{\text{hybrid}} = 0.55 \cdot S_{\text{dense}} + 0.30 \cdot S_{\text{lexical}} + 0.15 \cdot W_{\text{authority}}$$
   where $W_{\text{authority}}$ ranges from $1.00$ for machine-verified benchmark tables down to $0.40$ for historical logs.

## 4. Evidence Validation & Safety Layer

Before any evidence record enters the unified `InvestigationContext`, it passes through `EvidenceValidator`:
- **Prompt Injection Defense**: Evaluates incoming questions and text passages against regex patterns for prompt injection (`ignore previous instructions`, `system: you are`, `<script>`, `exec()`). Injected vectors are sanitized and tagged.
- **Metric Verification**: Validates quoted performance metrics against the authoritative benchmark dictionary (`final_test_results.csv`), rejecting unverified claims exceeding tolerance $\epsilon = 10^{-4}$.
- **Temporal Access Gate**: Ensures no future ground-truth labels leak into historical evaluations.

## 5. Architectural Certification

This dual-track architecture guarantees that the future Phase 3 LLM agent will reason strictly from verified, traceable, point-in-time compliant evidence without ever fabricating transaction features, inventing criminal histories, or leaking future test set labels.
